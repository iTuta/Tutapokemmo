# QQ 明雷报点推送

常驻脚本：监听 alphapedia（alpha.pokemmotools.org）的明雷报点，发现新明雷时推送消息。
**两个通道两套内容**：微信（企业微信群）看全量；QQ 群只报 `watchlist.json` 里登记的精灵，名单外的精灵一条都不报。头目两个通道都只在「出现」的那一刻报一次。支持两种通道：

- 微信（推荐，个人即可）：企业微信群机器人 webhook，零门槛。
- QQ：通过你自己的 QQ 开放平台机器人推送到指定群（需要企业/个人主体审核，视平台政策而定）。

## 使用前提

1. 微信通道：企业微信里建群 → 群设置 → 群机器人 → 添加机器人 → 复制 Webhook 地址，填到 `config.json` 的 `wechatWebhook`。个人即可，不需要企业资质。
2. QQ 通道：在 QQ 开放平台创建好机器人（群聊机器人），拿到 `AppID` 和 `AppSecret`（机器人开发设置里），把机器人拉进目标群（沙箱阶段需先在开放平台「沙箱配置」里把该群设为沙箱测试群）。
3. 本机或服务器能联网访问 alpha.pokemmotools.org 和 QQ 官方接口。

## 配置

编辑 `config.json`：

- `wechatWebhook`：微信通道填企业微信群机器人的 Webhook 地址；填了就走微信，其它 QQ 配置可忽略。
- `appId` / `appSecret`：QQ 通道的机器人凭证；未填 `wechatWebhook` 时必填。
- `sandbox`：`true` 表示沙箱环境（未发布时用），正式发布后改成 `false`。
- `groupOpenid`：目标群，可留空。留空时把机器人拉进群，或在群里 @机器人 发送「绑定」，脚本会自动写入。
- `onlyValuable`：`true` 时只推「有价值」的明雷。
- `regions`：只推指定地区，例如 `["合众", "神奥"]`；留空表示全部。
- `monsterIds`：临时覆盖关注名单，例如 `[176, 328]`；留空则用 `watchlist.json`（正式名单）。
- `pollIntervalMs`：轮询间隔，默认 15000（15 秒）。

## 关注名单（QQ 群只报哪些精灵）

编辑 `watchlist.json` 的 `monsterIds`（全国图鉴编号）：

```json
{ "monsterIds": [104, 126, 211, 300, 349, 357, 358, 412, 413, 439, 517] }
```

- **只影响 QQ 群**：微信通道照旧报全部精灵。
- 名单外的精灵在 QQ 群**一条都不报**：活跃明雷不报，各地区的「上次明雷」也不会提到它。
- `monsterIds` 显式写成 `[]` 才会给 QQ 群推送全部精灵；正常情况请保持有值。
- 文件缺失或格式不对时 QQ 群**一条都不报**（防止忘提交 watchlist.json 时把全部精灵刷进群），日志会写「关注名单读不到」。
- 优先级：环境变量 `SWARM_MONSTER_IDS` > `config.json` 的 `monsterIds` > `watchlist.json`。

## 运行

```bash
node scripts/qq-push/index.js          # 常驻运行（推荐用开机自启或计划任务）
node scripts/qq-push/index.js --once   # 定时模式（cron / GitHub Actions / 外部调度）：有新明雷或有新头目才发消息
node scripts/qq-push/index.js --test   # 发送一条测试消息验证通道
```

## 说明

- 已推送过的报点记录在 `seen.json`，重启不会重复推送；发送失败会进入 `pending.json` 自动重试。
- 定时模式（`--once`）：
  - **没有新报点就不发消息**（不再每轮刷一遍「无明雷」）。
  - 出现新明雷时才发：微信收到当前所有活跃明雷（含刚出现的），QQ 群只收到名单内的部分（一条名单内新明雷都没有就不发 QQ）。同一条明雷每个通道只报一次。
  - 地点显示为中文（映射自 `search-data.js`）。
- 头目（alpha）：**只在收到「头目出现」的那一轮发一条**（两个通道都发，不看名单），同一场头目（一场 4 小时 45 分）之后无论还剩多久都不再重复，也不再发「当前无活跃头目」。去重键是 `alpha:<这场头目的消失时刻>`，存在 `seen.json` 里（发送成功才写，所以发送失败下一轮会补报）；头目原始记录在 `boss-last.json`。
- 推送内容不含外链，避免触发 QQ 消息限制。
- 频控：群聊主动消息每个群每天最多 1000 条，明雷推送远用不满。
